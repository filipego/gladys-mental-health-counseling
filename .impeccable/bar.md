# Therapy audience accordion reference bar

- A full-width wine band owns the entire three-audience interaction; no cards, rounded shells, or inset container background.
- Each collapsed row is a three-column index: compact sequence number, audience name, and one-sentence summary aligned to the hero image rail.
- Hairline rules run edge to edge between rows while the row content stays on the existing 1200px page bound.
- Exactly one audience panel is open by default, and selecting another replaces the open panel rather than stacking multiple expanded sections.
- The open panel uses the same split as the page hero: reading copy on the left and a fixed-height photographic column on the right.
- The open heading carries the strongest hierarchy; row labels remain intentionally smaller and regular-weight.
- Expansion uses a smooth vertical reveal, preserves hash links for `#parents`, `#teens`, and `#adults`, and supports arrow-key movement between toggles.
- Mobile collapses to a single reading column with the image below the copy while preserving the wine field, row order, and readable spacing.
