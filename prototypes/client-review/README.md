# Client review — Home + About

Clean review set for Gladys Henriquez. Two pages only (plus light placeholders for unfinished routes).

## Open locally

From this folder:

```bash
python3 -m http.server 3003 --bind 127.0.0.1
```

Then open:

- http://127.0.0.1:3003/Home.html
- http://127.0.0.1:3003/About.html

Or open the HTML files directly in a browser.
